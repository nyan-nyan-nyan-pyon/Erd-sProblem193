# References and external context

This directory records external sources used to understand or motivate the project. It is not a claim that every source has been fully audited.

## Primary public construction

Cambie–Kalviainen, *An infinite small-step Z^3-walk with no collinear triple*, arXiv:2609.01766.

The public construction gives a finite-step infinite walk and supplies the 2-adic style of argument that motivated several constructions explored here.

## Erdős Problems discussion

Problem 193 forum thread:

https://www.erdosproblems.com/forum/thread/193

The forum is useful for current discussion and independent constructions, but statements from the thread should be distinguished from results proved inside this repository.

## Repository provenance note

The project also inspected the public repository `ekalvi/erdos-193` while comparing the Hilbert-style construction with later Gaussian/quaternary variants.

## Citation discipline

When adding a new external reference, record:

- title / authors;
- stable URL or identifier;
- what exact lemma, construction, or historical fact it is being used for;
- whether that use has been independently checked here.
