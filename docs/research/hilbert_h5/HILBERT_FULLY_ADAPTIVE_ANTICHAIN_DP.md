# Exact antichain dynamic program for fully adaptive fixed-L Hilbert selectors

## Status

This note records a theoretical reduction developed after the fixed-H1 additive-obstruction candidate.

It does **not** claim that a five-step fully adaptive selector exists or does not exist.
It gives an exact finite decision framework at any fixed suffix length `L`.

The main improvement over a fixed-menu relation test is that the physical menu is not chosen in advance.  The dynamic program propagates inclusion-minimal realizable menus of size at most `m` (in particular `m=5`) through the H1 substitution.

---

# 1. Fully adaptive setting

Fix a suffix length `L`, and write

```math
B=4^L,
\qquad
N=2^L.
```

Let the H1 context sequence be

```math
x_0x_1x_2\cdots,
```

where `x_a=(g_a,d_a)` is the audited 16-context sequence generated by

```math
\eta(g,d)=(g,S)(gS,I)(gS,T)(gC,Cd).
```

At each occurrence `a`, a fully adaptive selector may independently choose

```math
r_a\in D_{x_a}:=R_L(g_a).
```

Unlike a fixed H1 controller, two occurrences of the same context may use different offsets.

For an adjacent context edge `x->y` and offsets `r in D_x`, `s in D_y`, define the exact physical vector

```math
\Delta_{x,y}(r,s)
=
\left(
N e(g_x,g_y)+F_L(s)-F_L(r),
B+s-r
\right).
```

For fixed `L`, all domains are finite, so the physical-vector universe

```math
\mathcal V_L
=
\{\Delta_{x,y}(r,s):
(x,y)\in E(H1),
r\in D_x,
s\in D_y\}
```

is finite.

The fully adaptive `m`-step question is:

> Does there exist an infinite offset sequence `r_a in D_{x_a}` such that the set of distinct vectors `Delta_{x_a,x_{a+1}}(r_a,r_{a+1})` has cardinality at most `m`?

For the research target, `m=5`.

---

# 2. Finite-word menu families

Let

```math
W=x_0x_1\cdots x_n
```

be a finite H1 context word.

For endpoint offsets

```math
r\in D_{x_0},
\qquad
s\in D_{x_n},
```

define `Menus_W(r,s)` to be the family of physical menus realized by compatible offset paths

```math
r=r_0,r_1,\ldots,r_n=s,
\qquad
r_i\in D_{x_i},
```

where the path menu is

```math
M(r_0,\ldots,r_n)
=
\{\Delta_{x_i,x_{i+1}}(r_i,r_{i+1}):0\le i<n\}.
```

For deciding `|M|<=m`, supersets are never useful.
Therefore retain only inclusion-minimal menus of cardinality at most `m`:

```math
\mathcal A_W(r,s)
=
\min_{\subseteq}
\{M(r_0,\ldots,r_n):|M|\le m\}.
```

Here `min_subseteq` means delete every menu that strictly contains another realizable menu for the same endpoint pair.

The object `A_W` is a matrix indexed by finite endpoint domains, whose entries are finite antichains of subsets of `V_L`.

---

# 3. Base edge

For a one-edge word `W=xy`,

```math
\mathcal A_{xy}(r,s)
=
\bigl\{\{\Delta_{x,y}(r,s)\}\bigr\}
```

for each allowed endpoint pair `(r,s)`.

Thus the base transfer object is exact and contains no search approximation.

---

# 4. Exact composition law

Suppose

```math
W=W_1W_2
```

with one shared boundary context `z`, so a path through `W` is obtained by choosing a boundary offset `u in D_z`, a path through `W_1`, and a path through `W_2`.

Then

```math
\boxed{
\mathcal A_W(r,s)
=
\min_{\subseteq}
\left\{
A\cup B:
\begin{array}{l}
u\in D_z,\\
A\in\mathcal A_{W_1}(r,u),\\
B\in\mathcal A_{W_2}(u,s),\\
|A\cup B|\le m
\end{array}
\right\}.
}
```

This is an exact semiring-like composition, with

- path concatenation represented by menu union;
- alternatives represented by antichain union;
- supersets pruned by inclusion dominance;
- menus of cardinality greater than `m` discarded permanently.

## Why dominance pruning is exact

Suppose two realizable menus for the same endpoint pair satisfy

```math
A\subsetneq A'.
```

For every future continuation menu `B`,

```math
A\cup B\subseteq A'\cup B.
```

The path realizing `A` can be concatenated with the same continuation as the path realizing `A'`, because the endpoint offset is the same.
Therefore `A'` can never produce a smaller final menu than `A` and is safe to discard.

This is different from the earlier H5 warning: dominance is safe here because it is applied to **actual realizable path menus with the same boundary state**, not to relaxed edgewise label-cover objects later used for H6 relations.

# 5. Substitution recursion

For every H1 symbol `x`, define

```math
W_k(x)=\eta^k(x).
```

Because `eta` has constant length four, if

```math
\eta(x)=x_1x_2x_3x_4,
```

then `W_{k+1}(x)` is the concatenation

```math
W_k(x_1)W_k(x_2)W_k(x_3)W_k(x_4).
```

The antichain transfer object for `W_{k+1}(x)` is therefore obtained by repeated exact composition of the four level-`k` objects, including the exact boundary transition between the last context of one block and the first context of the next.

It is useful to store, for all 16 H1 symbols simultaneously,

```text
(first context, last context, antichain transfer matrix).
```

The update from level `k` to `k+1` is deterministic.

# 6. Finiteness

At fixed `L`, all of the following are finite:

- the 16 H1 contexts;
- every reset domain `D_x`;
- the vector universe `V_L`;
- the family of subsets of `V_L` of size at most `m`;
- the family of antichains of those subsets;
- the endpoint-offset pairs.

Therefore the full 16-symbol transfer tuple takes values in a finite state space.

Under repeated substitution, the tuple must eventually repeat.

Hence the exact adaptive-menu recursion is eventually periodic.

This turns an infinite selector question into a finite computation.

---

# 7. Infinite existence criterion without choosing a menu first

The starting H1 symbol `(I,S)` is prolongable: `eta(I,S)` begins with `(I,S)`.
Thus

```math
W_0(I,S)\prec W_1(I,S)\prec W_2(I,S)\prec\cdots
```

are nested prefixes of the infinite H1 context word.

For each `k`, a valid offset assignment on `W_k(I,S)` using at most `m` distinct physical vectors exists iff at least one entry of its antichain transfer matrix is nonempty.

Consider the tree whose nodes are valid offset assignments to these nested prefixes whose accumulated menu size is at most `m`.  Every level is finite because all reset domains are finite, and the tree is finitely branching.

If every level contains at least one valid assignment, Koenig's lemma gives an infinite branch.
Along one branch the prefix menus are nested nondecreasing sets, each of cardinality at most `m`; therefore their infinite union also has cardinality at most `m`.

Conversely, any infinite `m`-step selector restricts to a valid node at every level.

Thus:

```math
\boxed{
\begin{array}{c}
\text{There exists an infinite fully adaptive selector}\
\text{using at most }m\text{ physical vectors}
\end{array}
\iff
\begin{array}{c}
\text{every nested substitution prefix admits}\
\text{a path whose menu has size at most }m.
\end{array}
}
```

Because the exact transfer tuple is eventually periodic, this criterion is decidable after finitely many substitution levels.

Crucially, this test does **not** enumerate a candidate global menu `M` in advance.

---

# 8. Witness extraction

If the finite transfer-tuple evolution enters a repeating feasible state before any starting-prefix object becomes empty, retain predecessor pointers for antichain entries.

These pointers allow reconstruction of:

1. compatible finite offset assignments at arbitrarily large substitution depths;
2. a nested infinite branch by standard compactness / Koenig extraction;
3. the eventual physical menu, whose size is at most `m`.

For a practical certificate, one can store a finite lasso in transfer-state space plus the selected antichain entries and boundary offsets.

A candidate five-step witness must then be independently replayed through the direct Hilbert decoder.

# 9. Geometry after an adaptive menu witness

For a reset-compatible choice

```math
n_a=4^La+r_a,
\qquad
\chi_L(r_a)=\sigma(a),
```

the selected Hilbert index has the same terminal state (`I`) for every `a`.

The audited same-terminal valuation law gives

```math
V(H(n)-H(m))=\nu_2(n-m).
```

The standard collinearity contradiction uses all three pair differences.
If three selected points were collinear, write the adjacent height differences in lowest rational ratio

```math
h_2/h_1=p/q,
\qquad
\gcd(p,q)=1.
```

Comparing planar squared-norm valuations with height valuations for the first two differences forces `p,q` to have the same 2-adic valuation, hence both are odd.  The total difference then has scale factor `(p+q)/q`; since `p+q` is even, the planar squared norm gains twice the 2-adic valuation of `p+q`, while the height gains it only once, contradicting the same-terminal pair law for the total pair.

Therefore a verified reset-compatible adaptive selector with at most five physical steps would be a genuine five-step no-three-collinear Hilbert construction.

The hard part is menu feasibility, not a new collinearity search.

# 10. Practical pruning before antichain composition

The exact algorithm is finite but its worst-case antichain space can be large.  Several exact prunes are available.

## 10.1 Cardinality cap

Discard any union as soon as it contains `m+1` distinct vectors.

## 10.2 Inclusion dominance

For fixed endpoint offsets, retain only inclusion-minimal actual menus.

## 10.3 Endpoint equality

Antichains with different endpoint offsets must not dominate one another.  The boundary offset is part of the dynamic-programming state.

## 10.4 Physical-vector interning

Represent each exact vector in `V_L` by a canonical integer ID and each menu by a small immutable sorted tuple / bitset.

## 10.5 Symmetry

The audited H9 left-translation symmetry of the H1 context graph can be used to canonicalize equivalent transfer objects when the reset domains and physical-vector transform are transported together.  Any use beyond the exact H9 transport scope should be separately audited.

## 10.6 Lower bounds from relaxed cover

Before constructing full path antichains, an edgewise cover lower bound can prove that no menu of size at most `m` can even hit all required local transitions.  Such a lower bound is safe only as an exclusion; it must not replace the exact shared-offset DP for survivors.

# 11. Relation to H10/H11

H10 showed that, under a fixed low assignment, H6 relations are partial translations in upper-offset coordinates.  The fully adaptive physical-step version has the same elementary vertical property.

For a physical menu vector

```math
s=(s_x,s_y,s_z),
```

define

```math
d_s=s_z-B.
```

Whenever `s` is used from source offset `r` to target offset `r'`, the height coordinate forces

```math
\boxed{r'=r+d_s.}
```

Thus a fixed physical label acts as a partial translation on the reset-offset coordinate.  The planar coordinates and reset-state domains determine where that translation is actually allowed.

This can make the adaptive antichain composition much cheaper than a generic binary-relation implementation.

# 12. What this framework can settle

At a fixed suffix length `L`, an exact implementation can return one of three logically clean outcomes for `m=5`:

- **UNSAT:** at some finite substitution level the starting-prefix antichain object becomes empty, or the finite transfer evolution enters a cycle that has already certified impossibility;
- **SAT:** a repeating feasible transfer state yields a finite lasso / nested witness from which an infinite five-step selector can be extracted and directly replayed;
- **RESOURCE LIMIT:** implementation caps prevent completing the finite-state evolution; no mathematical conclusion is promoted.

No heuristic finite-prefix success should be called SAT, and no bounded search exhaustion short of the finite-state closure should be called UNSAT.

---

# 13. Recommended staged implementation

Before attempting the full `L=6`, `m=5` adaptive problem:

1. implement the antichain composition independently on a tiny synthetic word and verify against brute-force paths;
2. replay `L=2` where the domains are small;
3. replay a fixed-H1 selector as a degenerate case, confirming the known `m>=6` obstruction once independently audited;
4. run an `L=4` adaptive pilot and record antichain growth, endpoint-state counts, and eventual-repeat behavior;
5. only then attempt `L=6`.

The implementation should separate:

```text
mathematical state size
antichain count
menu-union attempts
cardinality prunes
inclusion-dominance prunes
substitution depth
transfer-tuple repeats
```

so that a structural bottleneck can be distinguished from an implementation bottleneck.

# 14. Research significance

The fixed-H1 short-cycle argument, if independently audited, closes the entire fixed 16-context family without further Hamming-weight enumeration.

The antichain DP then targets the first genuine escape route: occurrence-dependent reset choices.

This gives a clean hierarchy:

```text
fixed H1 16-context selector
    -> short-cycle additive obstruction candidate

longer-memory fixed finite controller
    -> lifted-cycle / state-splitting problem

fully adaptive fixed-L selector
    -> exact finite antichain substitution DP

irregular / variable-block Hilbert subsequences
    -> outside the present framework
```

This is the recommended theoretical and computational progression for testing whether a Hilbert-based five-step construction can exist.
