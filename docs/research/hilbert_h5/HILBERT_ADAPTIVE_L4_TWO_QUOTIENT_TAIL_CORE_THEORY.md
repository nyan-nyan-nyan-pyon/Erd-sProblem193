# Fully adaptive `L=4`: two-quotient recurrent-tail core theory

## Status

This note records theory developed after the audited H16 quotient-skeleton and
single-quotient closure.

Claim levels are separated deliberately.

- **AUDITED INPUT:** H15 fully adaptive `L=2`, H16 exact 62-quotient / 181-pair
  low-skeleton classification, and the same-terminal abelian-square
  obstruction.
- **ALGEBRAIC / FINITE CONSEQUENCE:** every infinite path in a finite low
  quotient graph eventually stays in a recurrent SCC; the H16 recurrent SCC
  counts therefore reduce the physical two-quotient problem to a finite list
  of tail cores.
- **PROOF CANDIDATE / NEXT AUDIT:** a shift-uniform 16-block obstruction for
  every such recurrent tail core at `L=4`.

This note does **not** yet prove the full fully adaptive `L=4` lower bound.
It does not make any `L>=6`, variable-block, irregular-subsequence, or global
Erdos-193 claim.

---

# 1. Audited low-quotient classification

H16 gives 62 exact low quotient values.  For unordered pairs of distinct
quotients there are

```math
\binom{62}{2}=1891
```

pairs, exactly 181 of which have a recurrent SCC in the 16-state low-suffix
graph.

The audited classification is

```text
{q0,q}, q != qstar                    : 60 pairs
{qstar,q}, q != q0                    : 60 pairs
non-special inverse r=-q              : 30 pairs
non-special complementary q+r=qstar   : 30 pairs
special {q0,qstar}                    :  1 pair
```

where

```math
q_0=(0,0,0),
\qquad
q_\star=(2,2,8).
```

For the inverse class, H16 found 112 recurrent SCCs in total, all strict
2-cycles.  For the complementary class it found 56 recurrent SCCs in total,
all strict 4-cycles.

The special pair `{q0,qstar}` has the eight antipodal SCCs

```math
\{a,a+8\},\qquad 0\le a<8,
```

with `q0` as the stay edge and `qstar` as the toggle edge.

# 2. Eventual-core lemma

Let `Q` be any fixed set of one or two low quotients, and let

```math
t_0,t_1,t_2,\ldots\in\{0,\ldots,15\}
```

be an infinite low path using only quotient labels in `Q`.

Because the low graph has only 16 vertices, the path eventually stays inside
one recurrent SCC of the directed graph generated by `Q`.

More concretely, after deleting loops inside a recurrent SCC, a transient
prefix cannot visit more than 16 distinct low states.  Hence an infinite path
enters a recurrent SCC after finitely many transitions; no physical argument
is needed for this statement.

Therefore a global five-step selector can exist only if one of the recurrent
tail cores itself admits an infinite continuation using a subset of the same
five physical vectors.

This is useful because the finite transient prefix can only add menu labels;
it can never repair an impossible recurrent tail.

# 3. Essential recurrent tails

The two 60-pair families involving `q0` or `qstar` have no new recurrent
structure:

- `{q0,q}`, `q != qstar`: every recurrent SCC is a `q0` singleton loop;
- `{qstar,q}`, `q != q0`: every recurrent SCC is a `qstar` antipodal 2-cycle.

Thus, once single-quotient impossibility is strengthened to be tail/shift
uniform, those 120 pair families disappear automatically.

The genuinely two-quotient recurrent tails are therefore:

```text
inverse strict period-2 SCCs       : 112
complementary strict period-4 SCCs :  56
special stay/toggle antipodal SCCs :   8
```

Equivalently, after the tail-uniform singleton check there are only

```math
30+30+1=61
```

nontrivial quotient-pair types left.

# 4. Aligned 16-block reduction

The coarse Hilbert state satisfies the two-digit factorization

```math
\sigma(16n+r)=\sigma(n)\,\chi_2(r),
\qquad 0\le r<16.
```

Hence every aligned block of 16 consecutive coarse indices is a global
Klein translation of the base length-16 state block.

Suppose a recurrent low core has already been entered.  Choose the next
aligned boundary `16n` after the entry time.  At that boundary the only
finite data relevant to a local obstruction are:

1. the global coarse-state translation

```math
k=\sigma(n)\in K;
```

2. the current phase/state in the recurrent low SCC;
3. the fully adaptive upper offset compatible with that occurrence.

Therefore an exact way to prove tail impossibility is:

> For every `k in K`, every recurrent low SCC, and every possible phase/start
> state of that SCC at an aligned boundary, show that no compatible upper
> path can cross one aligned 16-block while using at most five complete
> physical vectors.

If such a local block obstruction is established, no infinite tail in that
core exists, regardless of the transient prefix before it.

This avoids any assumption that H16's finite obstruction starting at coarse
index zero automatically applies to an arbitrary shifted tail.

# 6. Physical-label partition on strict cores

For an inverse or complementary strict core, the quotient word alternates
between two distinct quotients

```math
q,r,q,r,\ldots
```

(up to phase).

A complete physical vector has a unique low quotient, so a five-vector menu
splits disjointly as

```math
M=M_q\sqcup M_r.
```

Write

```math
a=|M_q|,\qquad b=|M_r|.
```

Then

```math
a,b\ge1,
\qquad
a+b\le5.
```

This quotient partition is exact; a physical label cannot migrate from one
side to the other.

# 7. Abelian-square pruning for a singleton side

The audited same-terminal theorem forbids adjacent abelian squares in the
physical-label word.

Assume, for example, that `a=1`.  Let the unique `q`-label be `A`.  Group the
strictly alternating word into consecutive two-edge blocks

```text
A b_0 | A b_1 | A b_2 | ...
```

where every `b_i` is an `r`-side physical label.

If two adjacent blocks of the `b`-word have the same Parikh vector, then the
corresponding adjacent blocks of the original physical word also have the
same Parikh vector, because each half contains exactly the same number of
copies of `A`.

Hence the `b`-word itself must be abelian-square-free.

A tiny exact exhaustive word check gives the maximum possible lengths of an
abelian-square-free word over alphabets of size 1, 2, and 3:

```text
alphabet size 1 : maximum length 1
alphabet size 2 : maximum length 3
alphabet size 3 : maximum length 7
```

Therefore an infinite strict two-quotient core with one singleton quotient
class cannot have the other class of size at most three.

Under the five-label cap, the only singleton-side split not eliminated by
this argument is

```math
\boxed{1+4}
```

(up to exchanging the two quotients).

The remaining possible size splits for an infinite strict core are therefore
contained in

```math
\boxed{(1,4),\ (2,2),\ (2,3)}
```

and their reversals.

This is only a necessary combinatorial filter; four-letter infinite
abelian-square-free words exist, so the `(1,4)` case is not excluded by word
combinatorics alone.

# 8. Deterministic physical-label transitions

For a complete physical label

```math
s=(w,h)
```

at suffix length `L=4`, define the centered height increment

```math
d_s=h-4^4.
```

Whenever the label is used,

```math
r_{n+1}=r_n+d_s.
```

Thus for a fixed candidate physical menu each label acts as a partial
translation on the full reset offset.  In two-digit coordinates

```math
r=16u+t
```

this becomes

```math
t'\equiv t+d_s\pmod{16},
```

with the upper offset determined by the integer carry.

Consequently the upper-core verifier should not use a generic many-to-many
relation for a fixed label.  It can use a deterministic partial transition
from the current offset and label.

# 9. Recommended H17 exact closure

The next exact task should proceed in this order.

1. Strengthen H16 single-quotient closure to aligned-block / global-translation
   form, so `q0` and `qstar` tails are excluded after arbitrary transients.
2. Reproduce the 112 inverse and 56 complementary recurrent SCCs from the
   H16 quotient maps.
3. For every aligned strict-core phase and global translation, run an exact
   endpoint-aware upper-offset menu antichain for one aligned 16-block.
4. Audit the `(1,4),(2,2),(2,3)` label-budget filter independently, but do not
   use it as the sole correctness mechanism; exact physical-vector antichains
   remain the primary closure.
5. Treat the eight special `{q0,qstar}` antipodal SCCs with stay/toggle choices
   by a joint low-state/upper-offset antichain.
6. Direct-replay every physical transition through the `L=4` Hilbert decoder.

If every aligned recurrent core is empty under a five-vector cap, the full
**at-most-two-low-quotient** `L=4` family is UNSAT, including arbitrary finite
transient prefixes.

# 10. Scope guard

Even a complete H17 two-quotient closure would prove only:

```text
Any fully adaptive L=4 five-step selector must use at least three distinct
low quotient values.
```

It would not yet prove the full fully adaptive `L=4` lower bound, because
three-, four-, and five-quotient recurrent skeletons would remain.

Nor would it imply an `L>=6` lower bound; adaptive scale lift goes in the
opposite direction for lower-bound propagation.
