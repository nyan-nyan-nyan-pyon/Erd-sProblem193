# Project status

Last structured update: 2026-09-13.

This file is the authoritative snapshot of what has been established, what is only a candidate, and what the next active task is.

## 1. Problem context

We study infinite walks in \(\mathbb Z^3\) generated by a finite set of fixed step vectors, with the requirement that no three visited points are collinear.

The project started from the Cambie–Kalviainen construction and then explored self-similar Gaussian/quaternary walks computationally and symbolically.

## 2. Audited 6-step construction — COMPLETE

Base radix-4 direction word:

\[
a=(1,i,-i,1).
\]

Define

\[
q_0=1,\qquad q_{4n+r}=a_rq_n,\qquad Z_n=\sum_{k<n}q_k.
\]

If \(q_n=i^{j_n}\), then the selected lift can be written directly as

\[
P_n=(4\Re Z_n+d^{(x)}_{j_n},\;4\Im Z_n+d^{(y)}_{j_n},\;16n+c_{j_n}),
\]

with

\[
d=((0,0),(-2,2),(-2,-1),(0,-3)),\qquad c=(0,8,5,13).
\]

The eight possible state transitions are

```text
0 -> 1
0 -> 2
1 -> 2
1 -> 3
2 -> 3
2 -> 0
3 -> 0
3 -> 1
```

and collapse to exactly six 3D step vectors:

```text
( 2,  2, 24)
( 2, -1, 21)
( 0,  1, 13)
(-2, -2, 24)
(-2,  1, 11)
( 0, -1,  3)
```

The key valuation identity is

\[
\nu_2(|Z_n-Z_m|^2)=\nu_2(n-m)
\]

when the endpoint states agree, and the tagged lift gives

\[
\nu_2(|W_n-W_m|^2)=\nu_2(H_n-H_m).
\]

This excludes collinear triples by the standard 2-adic argument.

Status: **audited / frozen**.

## 3. Fixed-scale <=5 impossibility — COMPLETE

Family:

\[
W_n=4Z_n+d_{j_n},\qquad H_n=16n+c_{j_n},
\]

with arbitrary integer \(d_j\in\mathbb Z^2\), integer \(c_j\), and positive adjacent height increments.

Because the directed state-transition graph has diameter 2, positivity implies, after the gauge \(c_0=0\),

\[
|c_j|\le 30.
\]

This is a theorem-derived exhaustive bound, not an artificial search box.

### 3.1 Initial computational search

Exact partitions of the eight transition edges were enumerated.

For exact 5 classes:

- total partitions: 1050;
- linearly feasible: 866;
- all 866 were UNSAT with no unresolved cases.

The horizontal tags were completely unbounded in the final fixed-scale search.

### 3.2 Extracted certificate

The 866 SMT cases were equipped with replayable UNSAT cores and independently replayed 866/866.

### 3.3 Reduced independent certificate

The final result no longer depends on Z3. A standard-library-only checker reconstructs the full argument using exact rational/integer arithmetic and finite mod-16 residue enumeration.

The 1050 exact-5 partitions split as

\[
\boxed{1050=184+164+675+27}.
\]

- **184**: step-equality system inconsistent over \(\mathbb Q\);
- **164**: rank-9 unique rational tag solution is nonintegral;
- **675**: rank-9 unique integer solution fails \(P_{0,4}\) or \(P_{3,7}\);
- **27**: rank-6 affine families are eliminated by complete mod-16 residue enumeration using only
  \[
  P_{2,4},\;P_{1,5},\;P_{1,3},\;P_{0,4}.
  \]

The linear contradictions compress under state rotation to 22 human-readable obstruction types; the 27 rank-6 exceptions compress to 8 rotation orbits.

Status: **rigorous inside this fixed-scale family / frozen**.

## 4. What is NOT established

The repository does **not** establish any of the following:

- that every Erdős-193 walk needs at least 6 step vectors;
- that a 5-step construction is globally impossible;
- that the four-state tagged-lift ansatz is exhaustive among all reasonable constructions;
- that changing the base walk cannot yield 5 steps;
- that adding hidden states cannot yield 5 steps.

Whenever the fixed-scale theorem is cited, include its family restriction.

## 6. Active task — FREE-SCALE 5-STEP SEARCH

Current family:

\[
W_n=A Z_n+d_{j_n},\qquad H_n=Mn+c_{j_n},
\]

where

- \(A\in\mathbb Z[i]\);
- \(M\in\mathbb Z_{>0}\);
- \(d_j\in\mathbb Z[i]\);
- \(c_j\in\mathbb Z\);
- the same four base states \(j\in\mathbb Z/4\mathbb Z\) are used.

For same-state endpoint pairs the tags cancel. Combining that with the base valuation lemma gives the necessary scale relation

\[
\boxed{\nu_2(|A|^2)=\nu_2(M)}.
\]

The immediate task is to turn this into a useful normalization/classification of scale classes before launching a broad 5-step search.

See `experiments/free_scale/README.md`.

## 7. Planned stage after free-scale

If the entire mathematically normalized four-state free-scale family is exhausted without a 5-step construction, move to hidden-state finite transducers.

The target there is to allow more internal states while still collapsing all actual transitions to at most five 3D step vectors.

## 8. Research stop conditions

For the current stage, stop and audit before continuing if any of the following occurs:

- a 5-step SAT survivor is found;
- the scale normalization derivation reveals another invariant;
- a solver result depends on a finite arbitrary box not justified by normalization;
- any contradiction with the frozen 6-step or fixed-scale certificate appears;
- any `TIMEOUT`, `UNKNOWN`, or implementation error prevents completeness.
