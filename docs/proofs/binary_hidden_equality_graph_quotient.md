# Binary-hidden equality graph quotient

## Scope

This note concerns the exact physical-step equality problem for the fully reachable binary-hidden triangular radix-4 cocycles. It does **not** identify indexed walks for direct-geometry purposes.

Let the hidden state be

\[
\sigma=(j,h)\in \mathbb Z/4\times\mathbb Z/2,
\]

and let `E` be the exact adjacent-transition set of one fully reachable cocycle. For an edge

\[
e=(s,t),\qquad s=(j,h),
\]

the normalized horizontal equality equation is

\[
z_{c(e)}=i^j+d_t-d_s.
\]

The vertical equality coordinate is automatic in the current positive-height family by taking all vertical state tags zero.

## 1. Equality depends only on the adjacent edge graph and source phase

The cocycle digit table itself does not enter the equality equations once the exact adjacent-transition set is known. Thus two cocycles with the same labeled edge set `E` have exactly the same equality-feasibility problem.

This observation is equality-only: the cocycles can still generate different indexed edge words.

## 2. Hidden relabeling and quarter-turn equivalence for equality

For `k in Z/4` and an arbitrary hidden relabeling

\[
g:\mathbb Z/4\to\mathbb Z/2,
\]

define

\[
F_{k,g}(j,h)=(j+k,\,h\oplus g(j+k)).
\]

Suppose `F_{k,g}` maps one adjacent edge set bijectively onto another:

\[
E' = F_{k,g}(E).
\]

Transport the edge coloring by

\[
c'(F_{k,g}(e))=c(e).
\]

If `(z,d)` solves the equality system on `E`, set

\[
z'_a=i^k z_a,
\qquad
 d'_{F_{k,g}(s)}=i^k d_s.
\]

Then for every `e=(s,t)`,

\[
\begin{aligned}
z'_{c'(F(e))}
&=i^kz_{c(e)}\\
&=i^k\bigl(i^{j(s)}+d_t-d_s\bigr)\\
&=i^{j(F(s))}+d'_{F(t)}-d'_{F(s)}.
\end{aligned}
\]

Hence equality feasibility is preserved in both directions. The transport is invertible and preserves the dimension of the rational solution space and the cycle nullity.

Therefore the equality problem may be quotiented by the finite group generated by:

- the four global phase quarter-turns `j -> j+k`;
- the sixteen independent swaps of the two hidden labels inside the four phase classes.

This is a group of at most `4*16=64` state relabelings on a fixed edge graph.

### Anchoring caveat: this is not a global cocycle-sequence quotient

The normalized cocycle universe is anchored by

\[
\phi(0,0)=0.
\]

For digit `r=0`, the base phase does not change. Therefore under a hidden gauge relabeling the two gauge terms occur at the same phase and cancel, so every bit

\[
\phi(j,0)
\]

is gauge-invariant.

A phase quarter-turn by `k` sends the anchored entry to

\[
\phi'(0,0)=\phi(-k,0).
\]

For a general cocycle this can equal one, and no gauge transform can repair it. For example the normalized class `0x0010` quarter-turned by `k=3` gives raw mask `0x0001`, which has `phi(0,0)=1` and lies outside the normalized 4096-class slice.

Thus the state relabeling above is an exact **equality-graph equivalence**, but it must not be promoted to an all-cocycle indexed-sequence equivalence. The earlier 18-edge sequence transport remains valid only because that special family satisfied the additional anchoring conditions proved there.

## 3. Cycle-space formulation

Let `D` be the reduced edge-state incidence matrix, with one state-potential column removed, and let

\[
B=(\Re b,\Im b,\mathbf1),
\qquad b_e=i^{j(\operatorname{source}(e))}.
\]

For a five-color indicator matrix `C`, the equality equations are

\[
Cx=B_{\rm hor}+Dp
\]

coordinatewise. If `Y` spans the left nullspace of `D`, this is equivalent to

\[
YCx=YB_{\rm hor}.
\]

The projected three-column matrix

\[
YB=(Y\Re b,Y\Im b,Y\mathbf1)
\]

controls the minimum possible rank of the five-color cycle matrix `YC`.

Using ranks without explicitly constructing `Y`,

\[
\operatorname{rank}(YB)
=
\operatorname{rank}[D\ B]-\operatorname{rank}D.
\]

Thus the structural census can verify the RHS rank by small exact rational linear algebra on at most 32 edge rows.

## 4. Consequence when the RHS rank is three

If

\[
\operatorname{rank}(YB)=3,
\]

then every rationally feasible exact-five coloring satisfies

\[
\operatorname{rank}(YC)\ge3.
\]

With five colors,

\[
h:=5-\operatorname{rank}(YC)\le2.
\]

Therefore only the three nullity types

\[
 h=0,1,2
\]

can occur. In the eight-state tag formulation these correspond to tag ranks

\[
21,18,15.
\]

Whether `h=2` is actually possible is a further coloring question and is not decided by this rank bound alone.

## 5. Equality quotient versus indexed geometry

The graph quotient in this note is deliberately stronger than cocycle gauge equivalence: two nonconjugate cocycles can have the same adjacent edge graph and therefore the same equality problem.

That does **not** imply that their canonical indexed edge words agree. Consequently:

- BIN0/BIN1/BIN2 may quotient equality by the graph equivalence above;
- BIN3 must return to the actual anchored cocycles, or to a separately proved subset-specific sequence-level conjugacy, before making a direct-geometric conclusion.

No global sequence quarter-turn quotient is asserted for the 4095 normalized cocycles.

## Claim boundary

This note gives an exact equality-feasibility quotient. It does not assert that any five-coloring exists, does not classify rank 15, and does not prove non-collinearity or collinearity for any indexed walk.
