# Proof sources

Canonical audited proof notes live here.

- `six_step_audit.tex` — audited triangular six-step construction and its 2-adic no-collinear-triple proof.
- `fixed_scale_optimality.tex` — fixed `A=4, M=16` four-state optimality under the old valuation certificate.
- `free_scale_four_state_optimality.md` — free-scale four-state optimality under the old all-pairs valuation certificate.
- `four_state_rho_triangle_optimality.md` — RHO1/RHO2 strengthening to the weaker triangle-local rho certificate.
- `hidden_state_phi0042_optimality.md` — `phi=0x0042` six-step optimality under the old valuation certificate.
- `hidden_state_phi0042_rho_optimality.md` — HS3R strengthening for `phi=0x0042` to the weaker triangle-local rho certificate.

All optimality statements here are family-specific. None is a global proof that Erdős Problem 193 requires six steps.

A rho-monochromatic triangle is generally only a failure of the rho certificate, not automatically a geometric collinear triple. Where a proportional-`Xi` witness is used, however, the full normalized three-dimensional displacement vectors are proportional; that stronger fact may be used explicitly in later direct-geometry work.

Generated PDFs and TeX auxiliary files are not canonical sources and are not committed by default.
